# Batalha do Saber — A.R.S. HTML GAMES e APPS

Quiz em equipes (4º ano) para TV/HDMI. 200 questões (40 por matéria), trilha 01–200, placar, pódio. PWA estático para GitHub Pages.
Abra `index.html` ou publique a pasta inteira (Settings → Pages → Deploy from branch).
Configurações: tempo (1/2/3/5 min), sons, vibração, efeitos, tela cheia, ACABAR PARTIDA.
